Application Programming Interface: forma de comunicação entre computadores ou programas de computadores.

Comunicação entre softwares ou computadores. 

Ex.: Faz a integração entre um app e um banco de dados

Ex. 2: Site que lista todos os feriados de cada país, disponibiliza o acesso as suas informações através de uma API.

Utilizando essa API em nosso software, não será necessário cadastrar manualmente cada data de feriado, e sim apenas chamar essa API.
a API também valida a requisição (Request) e verifica se ela é valida e se a  informação desejada é valida e está disponível no banco de dados. Caso certa informação não for disponível, é comum que a API retorne o status: 404, not found.
