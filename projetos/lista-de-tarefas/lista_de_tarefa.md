# PROJETO `Lista de tarefas`
## Objetivos
- Programa console capaz de gerenciar uma lista de tarefa.  
Será possivel realizar todo o CRUD as tarefas.

A tarefa conterá as seguintes propriedades:
- Nome
- Descrição
- Data Criada
- Data alvo (quando será realizada)
- Status, podendo variar entre aguardando, a fazer, e em atraso.
